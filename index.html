Free Cloud Database Sync (Supabase)

Connect a free Supabase project (500 MB Postgres free forever) so your CRUD edits sync across your phone, tablet, and laptop.

1-Minute Setup SQL (Run in Supabase SQL Editor):

create table if not exists tracker_store (
  id text primary key,
  payload jsonb not null,
  updated_at timestamptz default now()
);
